## 接線

### 認證與身份隔離

- `api/runtime.tsx` 提供 runtime access gate。角色、名稱、scope、模式與到期時間取 session；access code 僅表單 state，成功即清除，token 僅既有記憶體/sessionStorage。
- `main.tsx` 的 routes/aliases 都經過 gate；教師可使用學習教材預覽，但不發 student-only Agent。教師教材按鈕改成同分頁 RouterLink，維持目前 sessionStorage 身份。
- `api/client.ts` 的 session generation 防止舊 token 請求遲到的 401 清掉新身份；`auth.ts` 防止舊 session lookup 200 覆蓋新身份。同一 session 的 401 仍清理。
- 登出、過期、401、換 token 取消 query、清 QueryClient/Agent registry、重掛個人頁面；附件 blob URL 在 component cleanup revoke。請求成功後也再次確認 generation，避免身份已切換時仍導航。
- Profile PUT 成功另外 invalidate `['session']`，header 名稱立即更新；一般 Agent 追問不額外 exchange access code。

### 聊天、附件、歷史

- 首頁以 `auto` 送真 `/agent/chat`；圖片先 upload，再提交實際 attachment ID。結果直接導航 `?conversation=<id>`。
- `api/chatSession.ts` 共用 Agent submission：每次新動作建立 key，同次失敗重試沿用 submission/body；直接 q/topic/category 入口以當前 navigation/session key 共用提交，StrictMode 不重送。成功以 conversation ID replace URL，GET detail 顯示完整持久訊息。
- History reopen/reload 只 GET detail，不把 title/q 當新問題。`components/StudentData.tsx` 提供兩頁共用抽屜；list 使用 infinite query/nextCursor「載入更多」，delete 走真 API。
- Learning animation、練習、引用、追問從 API response/detail 取得；歷史的 active topic 與追問 context 依 API 內容，nullable/未知 animation 不呼叫動畫元件。
- Resource 的政策內容、資格狀態、文件、期限、窗口與來源來自 API；本機 scenario 僅供分類入口文案/視覺。未知期限明說需確認。建議追問送真 Agent，不再使用 timer/local reply。
- JPEG/PNG、5 MiB 使用 typed upload client 驗證；學習/資源 upload 失敗保留 draft/File，retry 可以重新 upload 後接 Agent。成功重試清理草稿；取消等待支援 upload AbortController 與當次 Agent submission。
- 歷史附件用帶認證的 binary fetch/blob 呈現。unsupported、network/provider error、cancel、429 使用錯誤狀態/重試，沒有本機假成功回覆。429 重新讀取 usage。

### Profile、memory、resources、alerts

- Profile GET/PUT 支援所有可編輯欄位；memory 同意 POST、刪除 DELETE，拒絕不 POST。已同意狀態依 profile memory，刷新後保留；不同 suggestion 重新判定。
- Resources list/detail 與 URL `?resource=<programId>` 使用 API；保留分類、搜尋、詳情、詢問學伴入口，顯示實際來源與期限/文件。
- Alerts list/read 使用 API，共用鈴鐺未讀點；action 依 target ID 打開 resource/detail、conversation 或 learning topic。移除明示是本次頁面隱藏，不冒充後端刪除。
- 聊天完成 invalidate usage/history/profile/alerts/resources/dashboard queries；首頁 header 顯示 server remaining。

### 儀表板

- Teacher/Government 頁面不再呼叫本機 event/aggregate generator 作最新資料。`api/dashboardPresentation.ts` 只將 server snapshot 轉為原圖表所需形狀。
- Teacher 使用 server roster/topics/trend/summary/previousSummary，篩選發真 API；CSV 依當前 server snapshot。正確率分母用 practice_count、動畫比率用 animation_observation_count，null 顯示未知/無紀錄。gap_count 文案為理解卡點/需鞏固訊號，不猜成已作答錯誤；個別學生主題的作答數直接使用 server correct_count/practice_count。
- Government 的 filters、圖表、detail、tracking snapshot、洞察與 CSV 使用 server aggregates。沒有加入個人/對話明細；CSV 從 daily aggregates 彙整。
- 偏好、教師複習計畫、政府追蹤清單繼續明示為本機瀏覽器功能，不宣稱後端寫入。資料日期以可讀日期顯示。
