## 完成內容

- 新增 backend 與 frontend Dockerfiles、`compose.yaml`、nginx reverse proxy、backend preparation entrypoint。Frontend build 固定 same-origin `/api/v1`，保留七個 HTML entry 與 SPA aliases。
- Backend UID/GID 10001，frontend 實測 UID 101。兩者 drop all capabilities 與 no-new-privileges；backend 不發佈 host port，前端預設綁 `127.0.0.1:8080`。
- 單一 Uvicorn worker、`--no-proxy-headers`、關閉 access log；nginx 移除 forwarded headers。Exchange rate 是經同一 nginx 的共用 bucket，Agent rate 仍按 principal 分開，文件明說單機限制。
- SQLite/uploads 使用 `backend_data` named volume、Chroma 使用 `chroma_data`。Volume 路徑與映像 `/app/data/{curriculum,policies,alerts}` source catalogs 分離；新 volume 寫入權限隨映像目錄 UID 帶入。
- Backend startup 依序做 seed、index、readiness，再以 exec 替換成 API process。準備失敗只印錯誤型別與設定提示，不印完整 exception/secret。`offline_demo` 不需要 live key；真實 provider 設定後補。
- Chroma `ANONYMIZED_TELEMETRY=False` 在映像及 Compose 明確設定，容器內實測為 false。
- nginx 使用 Docker DNS resolver，backend container 重建後能重解析服務；proxy_request_buffering off 讓 backend 在 parsing 前執行 body limits，保留 API JSON error；read/send timeout 55 秒容納 backend 45 秒 deadline。
- 新增 `scripts/create-demo-env.py`：依 `.env.example` 產生三個高熵不同 code，私有檔 0600、拒絕覆寫現有檔、不印秘密。Compose env_file 使用 raw 格式，server secrets 不傳入前端 build。
- `.dockerignore` 排除 env、node_modules、runtime DB/Chroma/uploads、CLI logs、測試產物與 backups；`.gitignore` 也排除 CLI/runtime/private backup，保留 source catalogs。
- README 與 `docs/demo-runbook.md` 說明啟停、設定、三角色 API smoke、Fake Demo 邊界、持久化/備份、原生 backend 開發及未來 live 設定。明確標示 3.2 尚未前端接線，未宣稱 browser Demo 已完成。

## 驗證結果

測試 harness 放在不提交的 `.codex-runs/`，沒有讀取真實 provider 或使用者 secrets。只以新產生的臨時code交換session；不印code/token。

1. **HTTP / API smoke**：`.codex-runs/4.2-api-smoke.py` / `.codex-runs/4.2-api-report.json`。
   - 15 個 HTML/SPA 路徑、health、Swagger/OpenAPI 通過。
   - 三角色 exchange、401、owner/role403、exact CORS、非法origin、過大JSON413、額外upload part422通過。
   - PNG真實上傳/下載、owner保護、Fake學習問題/追問/來源、`/chat`同key replay、不同body409通過。
   - 資源回覆建立pending suggestion；consent false422且不寫memory，true201後profile可查；通知已讀可查。
   - 不支援問題503且不扣額；teacher question +2、government event +3；最後used=3/reserved=0/remaining=17。
   - 改變 X-Forwarded-For 的無效exchange仍命中同rate bucket，429包含Retry-After。
   - 實際此次codes/token不在前端entry JS或容器logs中。
2. **Process restart persistence**：同一harness實際`compose restart`後，原token/session、quota、idempotency、profile、memory、history、已刪history、已讀通知、附圖bytes與teacher/government統計均保留；relogin不重置用量。
3. **Container recreation / volume persistence**：`.codex-runs/4.2-volume-recreate.py` / `.codex-runs/4.2-volume-report.json`。
   - 實際 `compose down` → `up -d --wait`。
   - 所有SQLite表逐row的canonical hash完全相同、附圖檔案hash相同、Chroma18/12counts相同。證明資料來自named volumes，並非僅保留舊container layer。
4. **Runtime boundary**：容器內實測backend UID10001/frontend UID101、單一worker/no-proxy-headers/no-access-log、volume owner10001、source catalogs在runtime之外、`/app/.env`不存在、Chroma telemetry=false。
5. **Startup failure**：`.codex-runs/4.2-startup-failures.json`。
   - 獨立`docker run --rm --network none`驗空access codes，以及明確live但缺必需設定，兩者exit1且不ready。
   - 只印sanitized failure，不含traceback或臨時codes；沒有外部provider呼叫。
6. **Env / source hygiene**：產生檔0600、三個不同code、stdout/stderr无secret、第二次拒絕覆寫且內容不變；git ignore排除logs/backups/Chroma，seed catalog仍可追蹤。Ruff、py_compile、git diff --check通過。

Build/up/test logs：`.codex-runs/4.2-build.log`、`4.2-rebuild.log`、`4.2-up.log`、`4.2-api-smoke.log`、`4.2-volume-recreate.log`。
