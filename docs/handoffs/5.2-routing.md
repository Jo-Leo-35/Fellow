# 5.2 — Auto routing for named physical laws

## 問題與修正

首頁以 `mode: auto`、不帶 `topic/category` 送出「請解釋牛頓第二定律」時，舊 `_hint_match` 對「牛頓」計 2 分，對 entropy 的「第二定律」計 4 分，錯誤選到 entropy；既有 offline coverage 正確拒絕不屬於該教材的問題，因此回 503。

此修復只改 `backend/app/services/agent.py` 的 `LEARNING_HINTS`，新增五個精確限定名稱：牛頓第一／第二／第三定律、熱力學第一／第二定律。上述牛頓提問因此取得 Newton 8 分，大於 entropy 4 分。沒有重寫通用 routing、沒有擴張 offline 教材內容或放寬 unsupported 判定，也未修改上一輪 catalog 修復、frontend 或其他 tests。

圖片仍如實標示 offline 不辨識圖片內容，教材回答只根據使用者文字；此次恢復的是首頁既有主題文字 routing。
